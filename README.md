# 딸기마을

논밭과 딸기 하우스 사이를 걷고, 딸기를 수확하고, 이웃과 이야기하는 온라인 3D 농장입니다.

[딸기마을에서 놀기](https://strawberry-village.web.app/)

## 조작

- 화면을 클릭하거나 터치한 곳으로 걷습니다. 방향키로도 걸을 수 있습니다.
- 스페이스바로 점프합니다.
- 마우스 드래그나 모바일 한 손가락 드래그로 캐릭터 주위를 둘러봅니다.
- 마우스 휠이나 모바일 핀치로 확대·축소합니다.
- 화면 아래 행동 버튼이나 표시된 숫자키로 주변에서 할 수 있는 행동을 선택합니다.
- 마을 지도를 펼치거나 장소 이름표를 눌러 길을 찾습니다.

## 농장 생활

- 하우스에서 딸기에 물을 주고 익은 딸기를 수확합니다.
- 선별장 안에서 **딸기 선별**을 선택해 바구니의 딸기 12알을 한 팩에 담습니다.
- 카페에서 딸기 우유·라떼·차를 주문하고 마십니다.
- 의자에 앉거나 바닥과 평상에 누워 쉬고, 뒷산 산책길을 걸어봅니다.
- 가까운 이웃에게 말을 걸면 캐릭터 위 말풍선으로 대화합니다.
